# 上游溯源与恢复说明（LanPaintBench）

本文件是受控目录中的上游溯源记录。上游克隆位于 `third_party/LanPaintBench/`，该目录含嵌套
`.git`，已被 `.gitignore` 忽略，因此**克隆本项目后该目录不存在**，需按本文恢复。

（`pipeline_lib_imagenet.py`、`guided_diffusion/`）。

## 调用约定（项目侧适配，不修改上游）

1. **掩码极性相反**：上游 `mask = 1` 表示*已知/保留*像素；本项目 `mask = 1` 表示*缺失*。
   调用上游前必须经 `app.data.mask_to_upstream`（`1 - mask`）取反。
2. **不使用 `run.py`**：该脚本在模块级解析 argparse、读取相对路径 `./checkpoints/...`，
   不适合作为库导入。本项目只导入 `pipeline_lib_imagenet` 与 `guided_diffusion`。
3. **官方采样参数来自 `makefile`**（而非 argparse 默认值）：
   `--ite_step_size 0.15 --uld_alpha 0 --uld_friction 15 --param_m 1 --sample_steps 20`，
   对应 `app.restore.RestoreConfig` 的默认值；`chara_lamb=8`、`chara_beta=1.0`。
4. **复现性**：`pipeline_lib_imagenet` 在导入时执行 `same_seeds(0)`，且 Langevin 使用全局 RNG
   （`torch.randn_like`）。因此每次推理前必须重设全局种子（`app.restore` 内已处理）。
5. **NFE 必须实测**：上游每次内层迭代会多次前向，无法用公式推断；本项目通过包裹
   `unet.forward` 计数（`app.restore._ForwardCounter`）。
