S4 掩码特征实测（`data/manifest.csv`，300 行；`boundary_norm = 边界像素数 / sqrt(缺失像素数)`）：
- 形状语义分层清晰：`center` ≈ `3.96` / `3.97`（两个面积档），`scratch` ≈ `50.0` / `60.96`，`scatter` ≈ `27.3` / `38.75`。
- 样本间区分度：100 个 `scratch` 样本中 `boundary_norm` 有 95 个不同取值，100 个 `scatter` 样本中有 90 个不同取值（`center` 因形状固定而仅 2 个取值，符合预期）。
