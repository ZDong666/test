## 恢复 S5 前必须处理

- 不同种子使用独立实验目录，防止配置、日志和指标覆盖。
- 重复实验从已有种子 42 基准的原图中固定子集，保证同图三种子可比较。
- 按 PRD 允许余数样本使用中预算，避免部分样本失败导致整批策略汇总跳过。
- 检测未提交代码或记录代码内容指纹，避免仅依赖 Git HEAD 导致错误复用缓存。
- 保存冻结的归一化参数、候选权重和单图阈值，测试集与界面只加载冻结参数。
